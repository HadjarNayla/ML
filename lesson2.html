📦 المتغيرات

قبل أن نتعلم المتغيرات، دعنا نرى لماذا نحتاجها أصلاً...

😤 مشكلة عمر العجوز

عمر الشايب كان يحب اسمه "عمر" كثيراً، كان عمره 50 سنة ولم يكن يحب ذلك. اتفرج على الكود وشوف المشكلة:

print("عمر الشايب")
print("كان يحب اسمه عمر كثيراً")
print("كان عمره 50 سنة")
print("لم يكن يحب أن يكون عمره 50 سنة")

اضغط "غيّر الاسم والعمر" وشوف كم خط لازم تغيّره!

🎉 بالمتغيرات تغيّر القيمة مرة واحدة فقط وتنعكس في كل مكان!
# تعريف المتغيرات مرة واحدة
name = "عمر"
age = 50
 
# الآن الكود يستخدم المتغيرات
print(name + " الشايب")
print("كان يحب اسمه " + name + " كثيراً")
print("كان عمره " + str(age) + " سنة")
print("لم يحب أن يكون عمره " + str(age) + " سنة")

⌨️ دالة input()

حتى الآن برامجنا تطبع فقط. ماذا لو أردنا أن يردّ المستخدم ويتفاعل مع البرنامج؟
هنا يأتي دور دالة input()

Python Terminal
>>> name = input("ما اسمك؟ ")
ما اسمك؟

📖 كيف تعمل input()

البرنامج يوقف تنفيذه وينتظر أن يكتب المستخدم شيئاً ثم يضغط Enter. ما يكتبه يُخزَّن في المتغير.

name = input("ما اسمك؟ ")
print("مرحبا، " + name)

⚠️ تحويل نوع البيانات

input() دائماً يُرجع نص (str)! لو أردت رقماً لابد تحوّله باستخدام int() أو float()

input() → str int(input()) → int float(input()) → float
age = int(input("كم عمرك؟ "))
print(age + 1)

🎮 جرّب بنفسك!
