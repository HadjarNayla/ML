01

الإعدادات الأولية وتجهيز القوائم

قبل بداية البرنامج، نجهّز القوائم (Lists) الفارغة التي ستخزن بيانات المرضى والأطباء والمواعيد والفواتير والأدوية، بالإضافة إلى اسم المستخدم وكلمة مرور الموظف.

المتغيرات المستخدمة

  • patients: قائمة تخزن كل مريض على شكل [الاسم، العمر، الجنس، الهاتف، العنوان]
  • doctors: قائمة تخزن كل طبيب على شكل [الاسم، التخصص، ساعات العمل]
  • appointments: قائمة تخزن كل موعد على شكل [اسم المريض، اسم الطبيب، التاريخ، الوقت]
  • invoices: قائمة تخزن كل فاتورة على شكل [اسم المريض، القيمة، الخدمة]
  • medicines: قائمة تخزن كل دواء على شكل [الاسم، السعر، الكمية]
  • employee_username / employee_password: بيانات دخول الموظف
clinic.py 
patients = []
doctors = []
appointments = []
invoices = []
medicines = []

employee_username = "admin"
employee_password = "1234"

تسجيل المرضى

تأخذ هذه الدالة بيانات مريض جديد من المستخدم عبر input()، وتضعها في قائمة واحدة (list) تمثل المريض، ثم تضيف هذه القائمة إلى القائمة الكبيرة patients باستخدام append().

المتغيرات المستخدمة

  • name, age, gender, phone, address: متغيرات مؤقتة تخزن مدخلات المستخدم
  • patient: قائمة صغيرة تجمع بيانات المريض الواحد
clinic.py 
def register_patient():
    name = input("أدخل اسم المريض: ")
    age = input("أدخل عمر المريض: ")
    gender = input("أدخل جنس المريض (ذكر/أنثى): ")
    phone = input("أدخل رقم هاتف المريض: ")
    address = input("أدخل عنوان المريض: ")

    patient = [name, age, gender, phone, address]
    patients.append(patient)

    print("تم تسجيل المريض بنجاح")

تبحث الدالة داخل قائمة patients عن مريض اسمه يطابق ما أدخله المستخدم، باستخدام for و if. المتغير found هو عدّاد رقمي (0 أو 1) يخبرنا إن كان البحث ناجحًا أم لا، بدل استخدام True/False.

المتغيرات المستخدمة

def search_patient_by_name():

    found = 0

    for patient in patients:

05

حذف مريض

تبحث الدالة عن المريض بالاسم داخل القائمة. بدل استخدام break لإيقاف الحلقة، نمر على كل المرضى ونبني قائمة جديدة new_patients تحتوي على كل من لا يطابق الاسم المطلوب حذفه، ثم نستبدل بها القائمة الأصلية باستخدام global.

المتغيرات المستخدمة

  • name: اسم المريض المراد حذفه
  • deleted: عدّاد يبدأ من 0 ويصبح 1 عند العثور على المريض وحذفه
  • new_patients: قائمة جديدة تحتوي على كل المرضى ما عدا المريض المحذوف
clinic.py 
def delete_patient():
    global patients
    name = input("أدخل اسم المريض المراد حذفه: ")
    deleted = 0
    new_patients = []

    for patient in patients:
        if patient[0] == name and deleted == 0:
            deleted = 1
        else:
            new_patients.append(patient)

    patients = new_patients

    if deleted == 1:
        print("تم حذف المريض بنجاح")
    else:
        print("لم يتم العثور على المريض")

تعديل بيانات مريض

تسمح للمستخدم بتحديث بيانات مريض موجود. إذا ترك المستخدم أي حقل فارغًا، تبقى القيمة القديمة كما هي دون تغيير (باستخدام if للتحقق من الفراغ).

المتغيرات المستخدمة

  • new_age, new_phone, new_address: القيم الجديدة المدخلة من المستخدم
  • patient[1], patient[3], patient[4]: عناصر داخل قائمة المريض يتم تعديلها مباشرة
  • found: عدّاد يبدأ من 0 ويصبح 1 عند العثور على المريض
clinic.py 
def edit_patient():
    name = input("أدخل اسم المريض المراد تعديله: ")
    found = 0

    for patient in patients:
        if patient[0] == name:
            found = 1
            print("اترك الحقل فارغاً إذا لم ترغب في تغييره")
            new_age = input("العمر الجديد: ")
            new_phone = input("رقم الهاتف الجديد: ")
            new_address = input("العنوان الجديد: ")

            if new_age != "":
                patient[1] = new_age
            if new_phone != "":
                patient[3] = new_phone
            if new_address != "":
                patient[4] = new_address

            print("تم تعديل بيانات المريض بنجاح")

    if found == 0:
        print("لم يتم العثور على المريض")

إلغاء موعد

بدل استخدام break، نمر على كل المواعيد ونبني قائمة جديدة new_appointments تحتوي على كل المواعيد ما عدا موعد المريض المطلوب إلغاؤه، ثم نستبدل بها القائمة الأصلية باستخدام global.

المتغيرات المستخدمة

  • patient_name: اسم المريض صاحب الموعد المراد إلغاؤه

clinic.py 
def cancel_appointment():
    global appointments
    patient_name = input("أدخل اسم المريض لإلغاء موعده: ")
    cancelled = 0
    new_appointments = []

    for appointment in appointments:
        if appointment[0] == patient_name and cancelled == 0:
            cancelled = 1
        else:
            new_appointments.append(appointment)

    appointments = new_appointments

    if cancelled == 1:
        print("تم إلغاء الموعد بنجاح")
    else:
        print("لم يتم العثور على موعد لهذا المريض")

قائمة المرضى حسب العمر

تقوم بترتيب نسخة من قائمة المرضى حسب العمر تصاعديًا أو تنازليًا، باستخدام خوارزمية ترتيب فقاعي (Bubble Sort) مبنية فقط على حلقتين while متداخلتين ومقارنات if، دون استخدام دوال ترتيب جاهزة.

المتغيرات المستخدمة

  • order: اختيار المستخدم بين الترتيب التصاعدي أو التنازلي
  • sorted_patients: نسخة من قائمة المرضى سيتم ترتيبها
  • n: عدد المرضى
  • i, j: عدّادات حلقتي while المستخدمتين في الترتيب
  • temp: متغير مؤقت لتبديل مكان مريضين أثناء الترتيب
clinic.py 
def patients_by_age():
    order = input("اكتب 1 للترتيب تصاعدياً أو 2 للترتيب تنازلياً: ")

    sorted_patients = []
    for patient in patients:
        sorted_patients.append(patient)

    n = len(sorted_patients)
    i = 0
    while i < n:
        j = 0
        while j < n - i - 1:
            if order == "1":
                if int(sorted_patients[j][1]) > int(sorted_patients[j + 1][1]):
                    temp = sorted_patients[j]
                    sorted_patients[j] = sorted_patients[j + 1]
                    sorted_patients[j + 1] = temp
            else:
                if int(sorted_patients[j][1]) < int(sorted_patients[j + 1][1]):
                    temp = sorted_patients[j]
                    sorted_patients[j] = sorted_patients[j + 1]
                    sorted_patients[j + 1] = temp
            j = j + 1
        i = i + 1

    index = 1
    for patient in sorted_patients:
        print(index, "- الاسم:", patient[0], "| العمر:", patient[1])
        index = index + 1

تشغيل البرنامج (تسجيل الدخول ثم القائمة الرئيسية)

قبل الدخول إلى القائمة الرئيسية، يجب على الموظف تسجيل الدخول بنجاح. تُمنح 3 محاولات كحد أقصى باستخدام حلقة while. القيمة 1 تعني نجاح الدخول، والقيمة 0 تعني الفشل (بدل استخدام True/False).

المتغيرات المستخدمة

  • login_success: يخبرنا إذا نجح تسجيل الدخول (1 نجاح / 0 فشل)
  • attempts: عدد المحاولات التي قام بها الموظف
clinic.py 
login_success = 0
attempts = 0

while login_success == 0 and attempts < 3:
    login_success = employee_login()
    attempts = attempts + 1

if login_success == 1:
    main_menu()
else:
    print("تم إغلاق البرنامج بسبب فشل تسجيل الدخول")
