المتغيرات في Python

تعلّمي كيف تخزّني البيانات، تسمّيها، وتستخدمها. هذا هو قلب البرمجة.

01
ما هو المتغير؟

المتغير هو كالصندوق المُسمَّى — تضعين فيه قيمة وتستخدمينها لاحقاً. في Python، لا تحتاجين لتحديد النوع مسبقاً، فقط اكتبي الاسم والقيمة!

📦

صندوق تخزين

المتغير يحفظ القيمة بداخله ويُعطيها اسماً يسهّل استخدامها لاحقاً.

🔁

قيمة قابلة للتغيير

يمكن تغيير قيمة المتغير في أي وقت خلال البرنامج.

🏷️

اسم تختارينه أنتِ

اختاري اسماً واضحاً مثل student_name ليكون الكود مفهوماً.

⚡

Python ذكي

Python يعرف نوع المتغير تلقائياً بمجرد إسناد القيمة إليه.

hello_variables.py
# إنشاء أول متغير لك / Creating your first variable
name       = "Naïla"    # نص / string
age        = 20         # رقم صحيح / integer
gpa        = 3.85       # رقم عشري / float
is_student = True       # صح أو خطأ / boolean
print(name)   # Naïla
print(age)    # 20
02
أنواع البيانات

كل متغير له نوع يعتمد على القيمة التي يحملها. في Python، هناك أربعة أنواع أساسية:

int
age = 21
أعداد صحيحة، موجبة أو سالبة.
float
pi = 3.14
أعداد عشرية. للقياسات والأسعار.
str
city = "Algiers"
نصوص. دائماً بين علامتي تنصيص.
bool
done = True
قيمتان فقط: True أو False.
💡
Python يحدّد النوع تلقائياً

لا تحتاجين لكتابة int age = 20. Python يقرأ القيمة ويحدد النوع بذكاء!

  • ✗

  • ✗

حلقة while

كرّري ما دام الشرط صحيحاً — ٦ محاور تفاعليين لفهم الحلقة من كل زاوية.

الأجزاء الثلاثة الإلزامية

كل حلقة while صحيحة تحتوي على ثلاثة أجزاء لا تعمل بدونها: التهيئة، الشرط، والتحديث.

① تهيئة ② شرط ③ تحديث
while_syntax.py
i = 0            # ① التهيئة — نقطة البداية
while i < 5          # ② الشرط — متى تستمر الحلقة؟:
    print(i)       # جسم الحلقة
    i += 1         # ③ التحديث — تجنّب الحلقة اللانهائية

ماذا يحدث بدون التحديث؟

إذا نسيت تحديث المتغير داخل الحلقة، لن تتغير قيمة الشرط أبدًا — وتصبح الحلقة لا نهائية.

infinite_loop.py
i = 0
while i < 5:
    print(i)
      # ⚠️ لا يوجد i += 1  →  حلقة لا نهائية!

لماذا لا تعمل الحلقة بدون التحديث؟

  • الشرط i < 5 يُفحص في كل دورة قبل تنفيذ الجسم.
  • إذا بقيت قيمة i صفرًا دائمًا، فالشرط سيظل True إلى الأبد.
  • Python لا تكتشف الحلقات اللانهائية تلقائيًا — المسؤولية عليك.
  • الحل: تأكد دائمًا أن المتغير المستخدم في الشرط يتغير داخل الجسم.

العد للأمام والخلف

عد تصاعدي
count_up.py
i = 0
while i < 5:
    print(i)
    i += 1
عد تنازلي
count_down.py
i = 5
while i > 0:
    print(i)
    i -= 1
المتغير i =
0

عدّ المحاولات

يُستخدم العداد لتتبع عدد الدورات: مفيد لتحديد عدد المحاولات المسموحة.

attempts.py
attempts = 0
max_tries = 3

while attempts < max_tries:
        # جرّب العملية
    attempts += 1

print("انتهت المحاولات")

متى تختار while بدلاً من for؟

  • استخدم for عندما تعرف عدد التكرارات مسبقًا.
  • استخدم while عندما يعتمد التوقف على شرط قد يتغير أثناء التنفيذ.
  • مثال: "كرر حتى يصح المستخدم الإجابة" — لا تعرف كم مرة مسبقًا.

قيمة التوقف (Sentinel)

بدلاً من العد، تستمر الحلقة حتى يُدخل المستخدم قيمة خاصة تُوقفها — مثل -1 أو "quit".

sentinel.py
total = 0
x = int(input("أدخل رقمًا (-1 للتوقف): "))

while x != -1:
    total += x       # تراكم
    x = int(input("أدخل رقمًا (-1 للتوقف): "))

print("المجموع:", total)
المجموع =
0

متى تستخدم نمط Sentinel؟

  • عندما يتحكم المستخدم في توقف البرنامج بنفسه.
  • قيمة التوقف يجب أن تكون خارج نطاق البيانات الصحيحة (مثل -1 للأعداد الموجبة).
  • نمط "اقرأ قبل الحلقة ثم اقرأ في نهاية الجسم" يضمن معالجة أول قيمة بشكل صحيح.

رفض المدخلات الخاطئة

نستخدم or لرفض قيمة خارج النطاق، وand لاشتراط تحقق شرطين معًا.

بوابة or
or_gate.py
while x < 0 or x > 100:
    x = int(input(
        "0-100: "))
نمط not valid
not_valid.py
valid = False
while not valid:
    x = int(input(
        "0-100: "))
    valid = 0 <= x <= 100

اضغط على رقم — هل يمر من البوابة؟

🔒

الفرق بين or و and في التحقق

  • or: يكفي أن يكون أحد الشرطين صحيحًا لرفض القيمة.
  • and: يجب أن يتحقق الشرطان معًا لقبول القيمة.
  • نمط while not valid أوضح قراءةً عندما يكون منطق الصحة معقدًا.
  • تستطيع كتابة 0 <= x <= 100 مباشرةً في Python.

استخراج الأرقام بـ % و //

n % 10 يُعطي آخر رقم، وn // 10 يُزيله. كرر حتى تصبح n == 0.

digit_extract.py
n = 4752
while n > 0:
    digit = n % 10     # آخر رقم
    print(digit)
    n = n // 10       # أزل آخر رقم
الرقم n =
4752

لماذا نستخدم % و // معًا؟

  • % (باقي القسمة): يُعطي ما تبقى بعد القسمة على 10 — دائمًا الرقم الأخير.
  • // (قسمة صحيحة): يُقسم ويتجاهل الكسر — يُزيل الرقم الأخير.
  • مثال: 4752 % 10 = 2 ثم 4752 // 10 = 475.
  • تنتهي الحلقة عندما تصبح n == 0 أي لم يتبق أرقام.

اختبارات القسمة وقانون دي مورغان

n % 2 == 0 يختبر الزوجية. قانون دي مورغان يُبسّط الشروط المنفية.

اختبارات القسمة
divisibility.py
n % 2 == 0     # زوجي
n % 2 != 0     # فردي
n % 3 == 0     # يقبل ÷3
n % 5 == 0     # يقبل ÷5
دي مورغان
demorgan.py
not(A and B)
  ⟺
not A or not B

not(A or B)
  ⟺
not A and not B

اضغط على A أو B لتغيير قيمتهما — شاهد كيف يتغير الناتج

A
B
A and B = True
A or B = True
not(A and B) = False
not(A or B) = False

تطبيق قانون دي مورغان في while

  • إذا أردت "لا زوجي ولا يقبل 3"، اكتب: not(n%2==0 or n%3==0)
  • بتطبيق دي مورغان: n%2!=0 and n%3!=0 — أسهل قراءةً.
  • القانون يُساعدك على تبسيط الشروط المعقدة وتجنب الأقواس المتداخلة.
✦
اختبري نفسك
❓ ما الجزء الذي إذا نسيناه تصبح الحلقة لا نهائية؟
❓ ما ناتج 4752 % 10؟
❓ ما المكافئ لـ not(A and B) بقانون دي مورغان؟

حلقة for

التكرار الأنيق على نطاقات وعناصر — مع range() وstep وأنيميشن تفاعلي!

🔬
تشريح حلقة for

قبل الأمثلة، دعينا نشرّح سطر for ونفهم معنى كل كلمة بالضبط:

for i in range(1, 6):
for

كلمة Python المحجوزة. تعني "لكل". تُعلم بداية الحلقة.

i

متغير الحلقة. يأخذ قيمة جديدة تلقائياً كل دورة.

in

تعني "من". تربط المتغير بمصدر الأرقام أو العناصر.

range(1, 6)

دالة تُولّد أرقاماً: 1، 2، 3، 4، 5.

1, 6

ابدأ من 1 وتوقف قبل 6. الرقم 6 نفسه لا يُنتج.

:

تُخبر Python أن جسم الحلقة يبدأ بالسطر التالي.

i
ما هو i؟ — متغير الحلقة

i هو متغير "السائق" — Python تُغيّر قيمته تلقائياً في كل دورة:

تنفيذ: for i in range(1, 6): print(i)
1
2
3
4
5
اضغط تشغيل لرؤية i يتغيّر ▼
[ ]
ما هو range()؟

range() تُولّد سلسلة أرقام — لها ثلاث صيغ:

1️⃣

range(stop)

range(5) → 0, 1, 2, 3, 4

2️⃣

range(start, stop)

range(1, 6) → 1, 2, 3, 4, 5

3️⃣

range(start, stop, step)

range(0, 10, 2) → 0, 2, 4, 6, 8

⚠️

stop غير مضمّن!

range(1, 6) تنتج 1 حتى 5 فقط.

مضمّن في range stop — غير مضمّن
↪↪
ما هو step؟

step يُحدد مقدار القفز بين كل رقم والتالي.

2️⃣

step=2

range(0, 10, 2) → 0, 2, 4, 6, 8

⬇️

step سالب

range(10, 0, -1) → 10, 9, 8, ... 1

يُؤخذ يُتخطى
01
أمثلة أساسية
for_basics.py
for i in range(1, 11):
    print(i)

for i in range(2, 21, 2):
    print(i)   # 2 4 6 ... 20

for c in "Python":
    print(c)   # P y t h o n

❓ ما الناتج؟ range(10, 0, -2)
❓ ما قيمة total بعد: total=0 → for i in range(4): total+=i؟

الشروط في Python

علّمي برنامجك كيف يفكّر ويتخذ قرارات بناءً على الظروف.

01
ما هي الشروط؟

الشروط تمنح برنامجك القدرة على اتخاذ القرارات. بدلاً من تنفيذ نفس الأوامر دائماً، يمكنك قول: «إذا كان كذا، افعل هذا، وإلا افعل ذاك».

if
الشرط الأساسي. إذا كان صحيحاً، نفّذ الكود بداخله.
elif
شرط إضافي يُختبر إذا فشل الشرط الأول.
else
الحالة الافتراضية إذا فشلت جميع الشروط.
first_condition.py
score = 75
if score >= 90:
    print("ممتاز! 🌟")
elif score >= 70:
    print("جيد جداً 👍")   # ← هذا سيُطبع
elif score >= 50:
    print("مقبول")
else:
    print("راجعي الدرس مرة أخرى 📚")
02
مشغّلات المقارنة
==يساوي
!=لا يساوي
>أكبر من
<أصغر من
>=أكبر أو يساوي
<=أصغر أو يساوي
⚠️
انتبهي: = vs ==

= للإسناد، أما == للمقارنة.
