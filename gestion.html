Introduction à Streamlit

Streamlit est une bibliothèque Python magique qui transforme un simple script Python en une application web interactive — sans aucune connaissance en HTML ou JavaScript. Dans cette séance, tu vas tout installer et lancer ta toute première application.

C'est quoi Streamlit ?

Imagine que tu veux partager ton analyse de données avec ton équipe. Normalement il faut faire un site web, ce qui est compliqué. Avec Streamlit, tu écris juste du Python normal et l'application web se crée automatiquement !

💡
Streamlit est utilisé par des data scientists chez Google, Uber, et des milliers de startups pour créer des dashboards et des applications de Machine Learning rapidement.

Installation

Ouvre ton terminal (invite de commandes) et tape cette commande :

terminal
# Installer Streamlit avec pip pip install streamlit # Vérifier que ça marche streamlit hello
ℹ️
Si tu vois une page web s'ouvrir avec une démo Streamlit, félicitations — l'installation a réussi ! Si tu as Python 3.8 ou plus, ça marchera sans problème.

Ton premier fichier Python

Crée un fichier qui s'appelle app.py et colle ce code dedans :

app.py
import streamlit as st # Titre de la page st.title("🎉 Ma Première Application Streamlit") # Afficher du texte simple st.write("Bonjour le monde ! Je suis une app Streamlit.") # Afficher du texte formaté (Markdown) st.write("Voici une liste : - Python 🐍 - Streamlit ⚡ - Data Science 📊") # Afficher un nombre age = 25 st.write(f"J'ai {age} ans.")
👁 Rendu dans le navigateur
🎉 Ma Première Application Streamlit

Voici une liste :

Lancer l'application

Dans ton terminal, va dans le dossier où tu as créé app.py et tape :

terminal
streamlit run app.py

Ton navigateur s'ouvre automatiquement sur http://localhost:8501. Chaque fois que tu sauvegardes ton fichier, l'application se met à jour instantanément !

⚠️
Pour arrêter l'application, appuie sur Ctrl+C dans le terminal. Ne ferme pas juste le navigateur.

Widgets et Interactions

Un widget est un élément interactif dans ton application : un bouton, un champ de texte, un curseur… Avec Streamlit, chaque widget retourne une valeur Python que tu peux utiliser directement dans ton code.

Le principe fondamental

La magie de Streamlit : quand l'utilisateur interagit avec un widget, le script Python se relance du début. La valeur du widget est capturée dans une variable et tu peux t'en servir.

🔄
Pense à ton script comme une recette : Streamlit la relit à chaque interaction. C'est pourquoi les widgets retournent toujours leur valeur actuelle.

Application de Gestion (CRUD)

CRUD = Create, Read, Update, Delete. C'est la base de toute application de gestion. Tu vas apprendre à ajouter, modifier et supprimer des données, puis les sauvegarder dans Excel.

Structure de l'application

L'application utilisera st.session_state pour garder les données en mémoire pendant que l'utilisateur navigue.

🧠
session_state est un dictionnaire spécial Streamlit. Les valeurs dedans persistent entre les relances du script. C'est essentiel pour stocker des données.

Initialisation et chargement

app.py
import streamlit as st import pandas as pd import os FICHIER = "employes.xlsx" # Charger ou créer le fichier if os.path.exists(FICHIER): df = pd.read_excel(FICHIER) else: df = pd.DataFrame(columns=["Nom", "Département", "Salaire"]) # Stocker dans session_state if "employes" not in st.session_state: st.session_state.employes = df

Ajouter un enregistrement

app.py (suite)
st.title("👥 Gestion des Employés") # ── FORMULAIRE D'AJOUT ── st.subheader("➕ Ajouter un employé") with st.form("form_ajout"): nom = st.text_input("Nom complet") dept = st.selectbox("Département", ["Ventes", "IT", "RH", "Finance"]) salaire = st.number_input("Salaire (€)", min_value=0, step=100) soumis = st.form_submit_button("Ajouter") if soumis and nom: nouvelle_ligne = pd.DataFrame({ "Nom": [nom], "Département": [dept], "Salaire": [salaire] }) st.session_state.employes = pd.concat( [st.session_state.employes, nouvelle_ligne], ignore_index=True ) st.success(f"✅ {nom} ajouté avec succès !")

Afficher et supprimer

app.py (suite)
# ── AFFICHAGE ── st.subheader("📋 Liste des employés") st.dataframe(st.session_state.employes, use_container_width=True) # ── SUPPRESSION ── st.subheader("🗑️ Supprimer un employé") if len(st.session_state.employes) > 0: index_suppr = st.selectbox( "Choisir l'employé à supprimer :", st.session_state.employes.index, format_func=lambda i: st.session_state.employes.loc[i, "Nom"] ) if st.button("🗑️ Supprimer", type="primary"): st.session_state.employes = st.session_state.employes.drop(index_suppr).reset_index(drop=True) st.success("Employé supprimé.")

Sauvegarder dans Excel

app.py (suite)
# ── SAUVEGARDE ── if st.button("💾 Sauvegarder dans Excel"): st.session_state.employes.to_excel(FICHIER, index=False) st.success(f"✅ Sauvegardé dans {FICHIER}")

🤖 Séance 09 · Avancé

Déploiement de Modèles ML

Le Machine Learning permet à l'ordinateur d'apprendre des patterns dans les données et de faire des prédictions. Streamlit rend ça accessible : tu vas entraîner un modèle et l'intégrer dans une interface.

C'est quoi le Machine Learning ?

Tu montres des exemples à l'algorithme (données + réponses connues), il apprend les patterns, puis il peut prédire la réponse pour de nouveaux exemples.

🌸
Exemple classique : les fleurs Iris. En donnant la taille des pétales, le modèle prédit l'espèce. C'est le "Hello World" du Machine Learning.
terminal
pip install scikit-learn joblib

Entraîner et sauvegarder un modèle

train_model.py (exécuter une seule fois)
from sklearn.datasets import load_iris from sklearn.ensemble import RandomForestClassifier from sklearn.model_selection import train_test_split import joblib # Charger les données iris = load_iris() X, y = iris.data, iris.target # Diviser : 80% entraînement, 20% test X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2) # Entraîner le modèle modele = RandomForestClassifier(n_estimators=100) modele.fit(X_train, y_train) # Évaluer score = modele.score(X_test, y_test) print(f"Précision : {score:.2%}") # Sauvegarder le modèle joblib.dump(modele, "modele_iris.pkl") print("✅ Modèle sauvegardé dans modele_iris.pkl")

Charger et prédire dans Streamlit

app.py
import streamlit as st import joblib import numpy as np # Charger le modèle (une seule fois grâce au cache) @st.cache_resource def charger_modele(): return joblib.load("modele_iris.pkl") modele = charger_modele() ESPECES = ["Iris Setosa 🌸", "Iris Versicolor 🌺", "Iris Virginica 🌼"] st.title("🌸 Prédiction d'Espèce d'Iris") st.write("Entre les mesures de la fleur pour identifier son espèce.") # Entrées utilisateur col1, col2 = st.columns(2) sep_l = col1.slider("Longueur Sépale (cm)", 4.0, 8.0, 5.5) sep_w = col2.slider("Largeur Sépale (cm)", 2.0, 4.5, 3.5) pet_l = col1.slider("Longueur Pétale (cm)", 1.0, 7.0, 4.0) pet_w = col2.slider("Largeur Pétale (cm)", 0.1, 2.5, 1.2) # Prédire if st.button("🔮 Prédire l'espèce", type="primary"): entree = np.array([[sep_l, sep_w, pet_l, pet_w]]) prediction = modele.predict(entree)[0] proba = modele.predict_proba(entree)[0] st.success(f"## {ESPECES[prediction]}") st.write("**Probabilités :**") for i, espece in enumerate(ESPECES): st.progress(float(proba[i]), text=f"{espece} : {proba[i]:.1%}")

import streamlit as st import pandas as pd import plotly.express as px from sklearn.preprocessing import LabelEncoder from sklearn.ensemble import RandomForestRegressor from sklearn.model_selection import train_test_split import io st.set_page_config(page_title="DataAnalyzer Pro", page_icon="🔬", layout="wide") st.title("🔬 DataAnalyzer Pro") st.write("Upload ton fichier de données et l'analyse se fait automatiquement !") fichier = st.file_uploader("📂 Charger un fichier CSV ou Excel", type=["csv","xlsx"]) if fichier: df = pd.read_csv(fichier) if fichier.name.endswith(".csv") else pd.read_excel(fichier) # ─── ONGLETS ─── tab1, tab2, tab3, tab4 = st.tabs(["📋 Données", "📊 Graphiques", "📈 Statistiques", "🤖 ML"]) with tab1: st.subheader("Aperçu des données") c1,c2,c3 = st.columns(3) c1.metric("Lignes", df.shape[0]) c2.metric("Colonnes", df.shape[1]) c3.metric("Valeurs manquantes", df.isnull().sum().sum()) st.dataframe(df.head(50), use_container_width=True) with tab2: st.subheader("Créer un graphique") colonnes_num = df.select_dtypes(include="number").columns.tolist() colonnes_cat = df.select_dtypes(include="object").columns.tolist() type_graph = st.selectbox("Type de graphique", ["Barres","Courbe","Nuage de points","Histogramme"]) if type_graph == "Histogramme" and colonnes_num: col_hist = st.selectbox("Colonne", colonnes_num) fig = px.histogram(df, x=col_hist) elif colonnes_cat and colonnes_num: x_col = st.selectbox("Axe X", colonnes_cat + colonnes_num) y_col = st.selectbox("Axe Y", colonnes_num) if type_graph == "Barres": fig = px.bar(df, x=x_col, y=y_col) elif type_graph == "Courbe": fig = px.line(df, x=x_col, y=y_col) else: fig = px.scatter(df, x=x_col, y=y_col) st.plotly_chart(fig, use_container_width=True) with tab3: st.subheader("Statistiques descriptives") st.dataframe(df.describe(), use_container_width=True) with tab4: st.subheader("Prédiction automatique") if len(colonnes_num) >= 2: cible = st.selectbox("Variable à prédire (cible)", colonnes_num) features = [c for c in colonnes_num if c != cible] if st.button("🚀 Entraîner le modèle"): X = df[features].dropna() y = df.loc[X.index, cible] X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2) mdl = RandomForestRegressor() mdl.fit(X_tr, y_tr) score = mdl.score(X_te, y_te) st.metric("Score R² du modèle", f"{score:.2%}") st.success("Modèle entraîné !")
