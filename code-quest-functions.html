نُعطي الدالة bake_cake نكهةً (وسيط · argument)، فتخلط وتخبز وتزيّن، وتُرجِع لنا كعكة (return)! غيّر النكهة وستتغيّر الكعكة، بنفس الدالة تماماً.

💡 نفس الدالة، نكهة مختلفة كل مرة = نتيجة مختلفة!

الآلة الحاسبة 🧮

آلة حاسبة حقيقية بدالة واحدة! تأخذ calc رقمين والعملية بينهما، وتُرجع الناتج. داخلها if تختار العملية الصحيحة. اختر + أو − أو × أو ÷ وجرّب!

💡 نفس الدالة تجمع وتطرح وتضرب وتقسم، حسب العملية التي تعطيها!

📜 البرنامج:

def calc(a, op, b):    if op == "+":        return a + b    if op == "-":        return a - b    if op == "×":        return a * b    return a / bcalc(6, "×", 3)
