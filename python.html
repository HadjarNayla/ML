01 — Concept

What is a variable?

📦

A storage box

A variable is like a labelled box. You give it a name, and inside it you store a value — a number, a word, anything.

🔁

Reusable & changeable

Unlike a constant, a variable's value can change over time. That's why it's called variable — it can vary.

🏷️

Named by you

You choose the name. Good names like student_age make your code easy to read and understand.

⚡

Instant in Python

Python creates variables the moment you assign a value. No need to declare types — Python figures it out.

hello_variables.py 
# Creating your first variable
name = "Naila"           # a text variable
age  = 20              # a number variable
gpa  = 3.85            # a decimal number
is_student = True     # a True/False value

# Using the variables
print(name)            # Output: Naila
print(age)             # Output: 20
02 — Data Types

Types of variables

Every variable has a type depending on what it holds. Python has four common types you'll use every day:

int
age = 21
Whole numbers, positive or negative. No decimals.
float
pi = 3.14
Decimal numbers. Used for measurements, prices, etc.
str
city = "Algiers"
Text. Always wrapped in quotes — single or double.
bool
done = True
Only two values: True or False.
types_demo.py 
# Check the type of any variable with type()
score = 95
price = 19.99
city  = "Ouargla"
pass_ = True

print(type(score))   # <class 'int'>
print(type(price))   # <class 'float'>
print(type(city))    # <class 'str'>
print(type(pass_))   # <class 'bool'>
💡
Python is dynamically typed

You never have to write int age = 20 like in some other languages. Python reads the value and figures out the type automatically. This makes code faster to write.

03 — Naming Rules

How to name a variable

  • ✓
    Start with a letter or underscore Valid: name, _score, my_var — Never start with a number.
  • ✓
    Only letters, numbers, and underscores Valid: student_name, value2 — No spaces or symbols like !, @, -.
  • ✓
    Use snake_case for readability Python style: first_name not FirstName or firstname.
  • ✗
    Avoid Python keywords Words like if, for, class, True are reserved — you can't use them as names.
  • ✗
    Case matters! Age, age, and AGE are three different variables in Python.
naming.py 
# ✓ Valid variable names
student_name = "Hadjar"
_count       = 0
level2       = "intermediate"

# ✗ Invalid names (these cause errors)
# 2cool = "no"      → starts with number
# my-var = 5        → hyphen not allowed
# class = "Python"  → reserved keyword
04 — Pro Tips

Multiple assignment

Python lets you assign variables in clever ways. These are shortcuts every Python programmer uses:

multi_assign.py 
# Assign the same value to multiple variables
x = y = z = 0

# Assign different values in one line
first, last, grade = "Hadjar", "Naila", "A"

# Swap two variables (Python magic!)
a, b = 10, 20
a, b = b, a   # now a=20, b=10

print(first, last)   # Hadjar Naila
print(a, b)          # 20 10
