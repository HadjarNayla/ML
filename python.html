المتغيرات في Python

تعلّمي كيف تخزّني البيانات، تسمّيها، وتستخدمها. هذا هو قلب البرمجة.

01
ما هو المتغير؟

المتغير هو كالصندوق المُسمَّى — تضعين فيه قيمة وتستخدمينها لاحقاً. في Python، لا تحتاجين لتحديد النوع مسبقاً، فقط اكتبي الاسم والقيمة!

📦

صندوق تخزين

المتغير يحفظ القيمة بداخله ويُعطيها اسماً يسهّل استخدامها لاحقاً.

🔁

قيمة قابلة للتغيير

يمكن تغيير قيمة المتغير في أي وقت خلال البرنامج.

🏷️

اسم تختارينه أنتِ

اختاري اسماً واضحاً مثل student_name ليكون الكود مفهوماً.

⚡

Python ذكي

Python يعرف نوع المتغير تلقائياً بمجرد إسناد القيمة إليه.

hello_variables.py
# إنشاء أول متغير لك / Creating your first variable
name       = "Naïla"    # نص / string
age        = 20         # رقم صحيح / integer
gpa        = 3.85       # رقم عشري / float
is_student = True       # صح أو خطأ / boolean

print(name)   # Naïla
print(age)    # 20
02
أنواع البيانات

كل متغير له نوع يعتمد على القيمة التي يحملها. في Python، هناك أربعة أنواع أساسية ستستخدمينها دائماً:

int
age = 21
أعداد صحيحة، موجبة أو سالبة. بدون فاصلة.
float
pi = 3.14
أعداد عشرية. للقياسات والأسعار وغيرها.
str
city = "Algiers"
نصوص. دائماً بين علامتي تنصيص.
bool
done = True
قيمتان فقط: True أو False.
types_demo.py
score = 95
price = 19.99
city  = "Ouargla"
passed= True

print(type(score))    # <class 'int'>
print(type(price))    # <class 'float'>
print(type(city))     # <class 'str'>
print(type(passed))   # <class 'bool'>
💡
Python يحدّد النوع تلقائياً

لا تحتاجين لكتابة int age = 20 كما في لغات أخرى. Python يقرأ القيمة ويحدد النوع بذكاء!

03
قواعد التسمية

اسم المتغير مهم جداً! إليكِ القواعد التي يجب اتباعها في Python:

  • ✓
    ابدأي بحرف أو شرطة سفليةصحيح: name، _score، my_var — لا يجوز البدء برقم.
  • ✓
    حروف وأرقام وشرطة سفلية فقطصحيح: student_name، value2 — لا مسافات ولا رموز مثل !، -.
  • ✓
    استخدمي snake_caseالأسلوب المفضّل: first_name وليس FirstName.
  • ✗
    تجنّبي الكلمات المحجوزةكلمات مثل if، for، class، True محجوزة ولا يمكن استخدامها كأسماء.
  • ✗
    الأحرف الكبيرة والصغيرة مختلفة!Age وage وAGE ثلاثة متغيرات مختلفة تماماً.
naming.py
# ✓ أسماء صحيحة / Valid names
student_name = "Hajar"
_count       = 0
level2       = "intermediate"

# ✗ أسماء خاطئة / Invalid names
# 2cool = "no"      → يبدأ برقم
# my-var = 5        → يحتوي شرطة عادية
# class = "Python"  → كلمة محجوزة
04
إسناد متعدد

Python يتيح لكِ إسناد متغيرات متعددة بأساليب ذكية في سطر واحد:

multi_assign.py
# نفس القيمة لعدة متغيرات / Same value
x = y = z = 0

# قيم مختلفة في سطر واحد / Multiple values
first, last, grade = "Hajar", "Naïla", "A"

# تبادل قيمتين بسطر واحد / Swap values
a, b = 10, 20
a, b = b, a   # الآن: a=20, b=10

print(first, last)   # Hajar Naïla
print(a, b)          # 20 10
✦
اختبري نفسك
❓ أيّ من هذه الأسماء صحيح في Python؟
❓ ما نوع المتغير price = 9.99؟
❓ ما الناتج؟ a, b = 5, 10 | a, b = b, a | print(a)

الشروط في Python

علّمي برنامجك كيف يفكّر ويتخذ قرارات بناءً على الظروف.

01
ما هي الشروط؟

الشروط تمنح برنامجك القدرة على اتخاذ القرارات. بدلاً من تنفيذ نفس الأوامر دائماً، يمكنك قول: «إذا كان كذا، افعل هذا، وإلا افعل ذاك». هذا هو منطق if / elif / else.

if
الشرط الأساسي. إذا كان صحيحاً، نفّذ الكود بداخله.
elif
شرط إضافي يُختبر إذا فشل الشرط الأول. يمكن تكراره.
else
الحالة الافتراضية. تُنفَّذ إذا فشلت جميع الشروط السابقة.
first_condition.py
score = 75

if score >= 90:
    print("ممتاز! 🌟")
elif score >= 70:
    print("جيد جداً 👍")   # ← هذا سيُطبع
elif score >= 50:
    print("مقبول")
else:
    print("راجعي الدرس مرة أخرى 📚")
02
مشغّلات المقارنة

داخل الشرط، تحتاجين لمقارنة القيم. إليكِ المشغّلات المتاحة في Python:

==يساوي
!=لا يساوي
>أكبر من
<أصغر من
>=أكبر أو يساوي
<=أصغر أو يساوي
operators.py
age = 20
name = "Naïla"

print(age == 20)      # True
print(age != 18)      # True
print(age >  25)      # False
print(age >= 20)      # True
print(name == "Hajar") # False
⚠️
انتبهي: = vs ==

= للإسناد (تضعين قيمة في متغير)، أما == للمقارنة (تتحققين من تساوي قيمتين). الخلط بينهما من أكثر الأخطاء شيوعاً!

03
الشروط المركّبة

يمكنك دمج شروط متعددة باستخدام المشغّلات المنطقية and، or، وnot:

  • and
    and — ويعطي True فقط إذا كان كلا الشرطين صحيحين. مثال: age >= 18 and has_id == True
  • or
    or — أويعطي True إذا كان أحد الشرطين صحيحاً على الأقل. مثال: day == "Sat" or day == "Sun"
  • not
    not — ليسيعكس قيمة الشرط. مثال: not is_empty — إذا كان الشرط False يصبح True.
logical.py
age    = 20
has_id = True
day    = "Sat"

# and: كلا الشرطين يجب أن يكونا صحيحين
if age >= 18 and has_id:
    print("مرحباً، ادخلي! ✅")

# or: أحد الشرطين يكفي
if day == "Sat" or day == "Sun":
    print("عطلة نهاية الأسبوع 🎉")

# not: عكس الشرط
if not has_id:
    print("ممنوع الدخول ❌")
04
الشرط المختصر

Python يتيح كتابة شرط بسيط في سطر واحد أنيق باستخدام صيغة الـ ternary:

ternary.py
score = 82

# الصيغة الطويلة
if score >= 50:
    result = "ناجح"
else:
    result = "راسب"

# الصيغة المختصرة (ternary) — سطر واحد!
result = "ناجح" if score >= 50 else "راسب"

print(result)  # ناجح

# مثال آخر / Another example
label = "مرتفع" if score > 75 else "منخفض"
print(label)   # مرتفع
💡
المسافة البادئة (Indentation) إلزامية!

في Python، الكود داخل الشرط يجب أن يكون مُبادَراً بـ 4 مسافات أو Tab واحد. هذا ليس اختيارياً — بدونه سيظهر خطأ!

if score >= 90: print("A") elif score >= 60: print("B") else: print("C")
❓ ما الفرق بين = و == في Python؟
❓ ما الناتج؟ x = "مرحبا" if 10 > 5 else "وداعاً"
